# 🏦 BankATMSimulator

A C# Console Application that simulates a real-world ATM system. This project was developed to strengthen my understanding of C#, Object-Oriented Programming (OOP), and core banking operations while following clean coding practices.

## Features
- 🔐 Secure PIN Authentication
- 👤 Account Registration
- 🔑 User Login
- 💰 Balance Inquiry
- 💵 Cash Deposit
- 💸 Cash Withdrawal
- 📄 Transaction History
- 🚪 Exit System

## Technologies Used
- C#
- .NET
- Object-Oriented Programming (OOP)
- Visual Studio 2022
